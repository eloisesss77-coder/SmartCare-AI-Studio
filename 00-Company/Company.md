# SmartCare AI Studio 公司档案

## 公司愿景

**让每一位老人的生活更安全、更健康、更有尊严。**

通过 AI + IoT 技术，为居家和机构养老提供 24 小时不间断的智能守护。

## 核心产品：SmartCare 智慧养老平台

SmartCare 是一套完整的智慧养老 SaaS 解决方案，通过 IoT 设备采集老人行为数据，经由 Zabbix 实时监控，结合 Dify AI 平台进行智能分析，为老人、家属、护理员和管理者提供及时、精准的养老关怀服务。

## 竞品差异化

| 维度 | 竞品（通用方案） | SmartCare |
|------|-----------------|-----------|
| 监控平台 | 自研或弱化 | Zabbix 专业监控，稳定性强 |
| AI 分析 | 简单阈值/规则 | Dify RAG + LLM 深度分析 |
| 告警推送 | 单一通知 | 分级推送 + AI 护理建议 |
| 知识库 | 无或浅层 | 专业养老知识库 RAG |
| 开放能力 | 封闭系统 | Zabbix API + Dify API 开放 |
