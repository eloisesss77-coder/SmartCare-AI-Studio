# SmartCare 统一输出格式规范

> 本文档规定所有 AI Agent 角色在对话中输出内容的统一格式，确保团队协作时信息传递高效、一致。

## 核心原则

1. **结构化**：每次输出用标题层级组织，不输出大段纯文本
2. **模板化**：每个角色有固定输出模板，下游角色一眼找到需要的部分
3. **Markdown**：所有输出使用 Markdown 格式（Trae 原生支持渲染）
4. **可追溯**：关键输出标注版本和关联任务编号

## 通用输出结构

所有 Agent 的正式输出（非闲聊）必须包含：

```
## [标题]：[主题名称]

### 1. [模块1]
内容

### 2. [模块2]
内容

### ...

### N. 下一步 / 交付 / 验收
```

## 信息层级规范

```
# H1 → 文档标题（每个输出只有一个）
## H2 → 主模块
### H3 → 子模块
#### H4 → 细节（尽量少用）

- 列表项
  1. 有序步骤

> 引用/提示/注意事项

**加粗** → 强调关键词
`代码` → 行内代码/文件名

--- → 分隔线（切换话题时使用）
```

## 禁止的输出方式

- ❌ 无标题不分段的大段纯文本（"老人跌倒是一个很严重的问题，我们应该..."）
- ❌ 输出与当前角色职责无关的内容
- ❌ 用"可能"、"大概"、"也许"等模糊词回避明确结论
- ❌ 超长代码不加注释
- ❌ 输出不完整的代码片段（如 `... // 省略` 而没有说明省略了什么）
