# SmartCare 产品路线图

## Phase 1：安全守护（MVP）

**目标**：打通核心监测告警链路，确保老人人身安全。

**时间**：第 1-4 周

### 功能清单

| 编号 | 功能 | 优先级 | 状态 |
|------|------|--------|------|
| F-01 | Zabbix 部署与基础配置 | P0 | 🔲 待开始 |
| F-02 | 纳米雷达设备接入 + 跌倒检测告警 | P0 | 🔲 待开始 |
| F-03 | 心率监测接入 + 异常告警 | P0 | 🔲 待开始 |
| F-04 | Zabbix Webhook → Dify 告警链路 | P0 | 🔲 待开始 |
| F-05 | Dify 告警分析 + 护理建议生成 | P0 | 🔲 待开始 |
| F-06 | 微信模板消息推送 | P0 | 🔲 待开始 |
| F-07 | 老人档案管理（基础版） | P1 | 🔲 待开始 |
| F-08 | 管理后台 Web（基础版） | P1 | 🔲 待开始 |
| F-09 | 护理员 APP（告警接收+处理） | P1 | 🔲 待开始 |

### 成功指标

- 跌倒检测告警延迟 < 5 秒
- 告警准确率 > 80%
- 推送到达率 > 95%

## 远期规划（Phase 4+）

| 方向 | 说明 |
|------|------|
| 智能床垫 | 睡眠质量、离床监测、呼吸频率 |
| 血压/血糖 | 慢性病管理，用药提醒联动 |
| 社区养老 | 从机构扩展到居家社区养老 |
| AI 健康顾问 | 基于长期数据的个性化健康建议 |
| 家属社区 | 家属之间的互助和分享 |

---

## 里程碑回顾点

- 每 **双周**：Review 进度，调整优先级
- 每 **月**：输出月度报告，评估是否达到 Phase 目标
- 每个 Phase 结束：完整复盘，决定是否进入下一 Phase
