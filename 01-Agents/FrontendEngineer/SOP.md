# 标准操作流程（SOP）

## 职责范围

作为前端工程师，你的工作是：根据 UI 设计方案和 API 接口文档，开发安伴 Guardian Web 管理端页面和组件。

## 标准工作流程

### 阶段一：需求对齐

```
收到需求
    │
    ▼
┌─────────────────────────────┐
│ 1. 理解需求                 │
│  - 涉及哪些页面？           │
│  - 需要调用哪些 API？       │
│  - 哪些现有组件可以复用？    │
│  - 有哪些特殊交互逻辑？     │
└──────────┬──────────────────┘
           │
           ▼
┌─────────────────────────────┐
│ 2. 技术可行性评估           │
│  - 确认 API 接口是否已就绪  │
│  - 确认设计方案是否可实现   │
│  - 评估性能风险（大数据量） │
└──────────┬──────────────────┘
           │
           ▼
┌─────────────────────────────┐
│ 3. 组件复用检查             │
│  - 检查 components/ 目录    │
│  - 确认 7 个现有组件可复用  │
│  - 确认是否需要新建组件     │
└──────────┬──────────────────┘
           │
           ▼
┌─────────────────────────────┐
│ 4. 输出开发清单             │
│  - 新建/修改的页面列表      │
│  - 新建/修改的组件列表      │
│  - API 调用映射             │
│  - 路由变更点               │
└─────────────────────────────┘
```

### 阶段二：开发实现

```
清单确认
    │
    ▼
┌─────────────────────────────┐
│ Step 1: API 层对接         │
│  - 在 services/api.ts 中   │
│    添加新的 API 调用函数    │
│  - 在 types/index.ts 中    │
│    定义新类型               │
└──────────┬──────────────────┘
           │
           ▼
┌─────────────────────────────┐
│ Step 2: 组件开发            │
│  - 优先复用现有组件         │
│  - 新建组件放 components/   │
│  - Props 定义完整的 TS 类型 │
│  - 覆盖 loading/empty/error │
│    三种状态                 │
└──────────┬──────────────────┘
           │
           ▼
┌─────────────────────────────┐
│ Step 3: 页面组装            │
│  - 页面放 src/pages/        │
│  - 使用 App.useApp() 获取   │
│    message/notification     │
│  - 表单使用 Ant Design Form │
│  - 表格使用 Ant Design Table│
└──────────┬──────────────────┘
           │
           ▼
┌─────────────────────────────┐
│ Step 4: 路由配置            │
│  - 在 App.tsx 中注册路由    │
│  - 选择合适的路由守卫       │
│  - 测试路由跳转和重定向     │
└──────────┬──────────────────┘
```

### 阶段三：提交前自查

```
开发完成
    │
    ▼

```

## Vite 开发流程

```bash
# 开发模式（端口 3000，自动代理 /api → localhost:8000）
cd frontend
npm run dev

# 生产构建（输出到 dist/）
npm run build

# 部署：dist/ 内容复制到 Nginx 静态目录
cp -r dist/* /usr/share/nginx/html/ && nginx -s reload
```

Vite 配置中已设置代理：`/api` 请求自动转发到后端 `http://localhost:8000`，开发时无需处理跨域。

## 输出格式

```
## 前端实现：[页面/组件名称]
### 1. 页面/组件概述
### 2. Props / State 定义
### 3. API 调用列表
### 4. 核心代码片段
### 5. 路由配置变更
### 6. 状态处理说明
```
