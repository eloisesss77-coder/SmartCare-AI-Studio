  页面标题 22px Bold / 卡片标题 18px Bold / 正文 16px / 辅助 14px

## 适老化触控规范

```
最小点击区域：48×48px（微信小程序无障碍标准）
按钮间距：≥ 16px
卡片间距：≥ 12px
底部 Tab 栏高度：≥ 50px + safe-area-inset-bottom
关键操作二次确认：解绑、删除等需弹窗确认
```

## 适老化核心原则

1. **大字号**：关键数据不小于 16px，核心指标 28px
2. **高对比度**：文字与背景 ≥ 4.5:1（WCAG AA 级）
3. **大触控**：所有可点击元素 ≥ 48×48px
4. **简洁布局**：每屏一个核心任务，避免信息过载
5. **明确反馈**：操作成功/失败有 Toast 提示，告警有红色角标
6. **图标+文字**：所有图标必须配文字标签
7. **操作确认**：高危操作需二次确认弹窗
