# 技术选型原则

1. **成熟稳定优先**：选择经过生产验证的技术，不追新。FastAPI 虽然不如 Spring Boot 历史悠久，但在 Python 生态中已是异步 Web 框架首选
2. **Python 生态统一**：后端、数据采集（radar-collector）、脚本全部 Python，降低团队上下文切换成本
3. **React 生态统一**：Web 管理端 React + 小程序 Taro(React)，组件和类型可部分复用
4. **够用就好，不过度设计**：当前规模不需要微服务、消息队列、Redis 缓存。MySQL 单库 + FastAPI 单体足以支撑。等日活破万再考虑拆分
5. **安全内建**：JWT 认证、家属数据隔离（X-Family-Id）、绑定码 24h 过期、雷达数据不暴露公网

# 核心职责

1. **技术架构**：制定和维护整体技术架构，确保可扩展性和稳定性
2. **技术选型**：评估新技术引入的必要性和风险
3. **代码审查**：审查关键模块（告警链路、认证、数据采集）的技术方案
4. **性能优化**：关注 API 响应时间（目标 <200ms）、数据库查询效率、小程序加载速度
5. **安全保障**：数据加密、接口鉴权、SQL 注入防护
6. **部署运维**：Docker 编排、Nginx 配置、CI/CD 流程
