## 国家养老标准

| 标准编号 | 名称 | 说明 |
|----------|------|------|
| GB/T 42195-2022 | 老年人能力评估规范 | 将老人分为自理、轻度失能、中度失能、重度失能四级 |
| GB/T 37276-2018 | 养老机构等级划分与评定 | 养老机构一至五级评定标准 |
| GB/T 35796-2017 | 养老机构服务质量基本规范 | 服务内容和质量要求 |
| MZ/T 039-2013 | 老年人能力评估 | 生活能力、精神状态、感知觉与沟通、社会参与 |

## 老年人能力分级

| 等级 | 名称 | 特征 | 护理要求 |
|------|------|------|----------|
| 0 级 | 自理 | 日常生活完全自理 | 健康监测、定期巡访 |
| 1 级 | 轻度失能 | 部分日常活动需协助 | 生活照料、健康管理 |
| 2 级 | 中度失能 | 大部分日常活动需协助 | 生活护理、康复护理 |
| 3 级 | 重度失能 | 完全依赖他人照料 | 特殊护理、24 小时看护 |

## 养老突发事件分类

| 类别 | 事件类型 | 响应级别 | 处置要求 |
|------|----------|----------|----------|
| 人身安全 | 跌倒、坠床、走失 | 🔴 紧急 | 5 分钟内到场，必要时送医 |
| 健康异常 | 心率异常、呼吸困难 | 🟠 重要 | 15 分钟内评估，记录处理 |
| 行为异常 | 久卧、徘徊、拒食 | 🟡 一般 | 1 小时内关注，通知家属 |
| 生活事件 | 饮食异常、排便异常 | 🔵 提示 | 24 小时内提醒，纳入日报 |
| 设备事件 | 设备离线、电量低 | ⚪ 设备 | 2 小时内检修 |

- 到 2025 年，养老机构普遍具备信息化服务能力
- 鼓励发展智慧养老，推动 IoT、AI 技术在养老服务中应用
- 建立老年人健康档案，实现健康数据动态管理

## 毫米波雷达在养老中的应用

### 技术原理
- **频率**：60GHz 毫米波雷达，通过发射电磁波并接收反射信号检测人体微动
- **非接触式监测**：无需穿戴设备，无需摄像头，主动式监测

### 核心优势
| 优势 | 说明 |
|------|------|
| **隐私保护** | 不采集视频图像，仅输出结构化数据（姿态/心率/呼吸），适合卧室、卫生间等私密空间 |
| **非接触无感** | 无需老人佩戴任何设备，24 小时自动监测，不影响正常生活 |
| **穿透性** | 可穿透衣物、被褥，检测呼吸和心跳微动 |
| **跌倒检测** | 毫秒级跌倒识别，主动告警，无需老人操作 |

### 可监测指标
| 指标 | 说明 |
|------|------|
| 跌倒检测 | 0=正常 / 1=跌倒，实时告警 |
| 心率监测 | 40-120 bpm 为正常范围 |
| 呼吸率 | 10-30 次/分为正常范围 |
| 在床检测 | 0=不在床 / 1=在床 |
| 活动量 | 静止/轻微/中等/剧烈，评估日常活跃度 |
| 姿态识别 | 躺/坐/站/走路，判断老人当前状态 |

### 与摄像头的对比
| | 毫米波雷达 | 摄像头 |
|----|-----------|--------|
| 隐私性 | ✅ 无图像采集 | ❌ 侵犯隐私 |
| 夜间可用 | ✅ 不受光线影响 | ❌ 需要红外补光 |
| 跌倒检测 | ✅ 实时主动检测 | ⚠️ 需 AI 视觉分析 |
| 老人接受度 | ✅ 高（无监控感） | ❌ 低（被监视感） |
| 心率/呼吸 | ✅ 支持 | ❌ 不支持 |

## 本项目告警四级体系与国家标准对应

安伴 Guardian 采用四级告警体系，与国家标准突发事件分类对应：

| 项目告警级别 | 值 | 图标 | 说明 | 对应国家标准 |
|-------------|------|------|------|-------------|
| `emergency` | 4 | 🔴 | 紧急告警（跌倒、严重心率异常） | 🔴 人身安全 - 紧急 |
| `critical` | 3 | 🟠 | 重要告警（心率偏高/偏低、呼吸异常） | 🟠 健康异常 - 重要 |
| `warning` | 2 | 🟡 | 一般告警（久卧、离床过长、活动异常） | 🟡 行为异常 - 一般 |
| `info` | 1 | 🔵 | 提示告警（设备离线、电量低） | 🔵 生活事件 + ⚪ 设备事件 |

### 告警处理状态
| 状态码 | 状态 | 说明 |
|--------|------|------|
| 0 | 未处理 | 告警新产生，待护理员确认 |
| 1 | 处理中 | 护理员已接单，正在处理 |
| 2 | 已处理 | 已完成处理，记录处理结果 |
