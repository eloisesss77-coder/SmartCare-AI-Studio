# 养老护理术语

## 核心术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 失能老人 | Disabled Elderly | 丧失生活自理能力的老人 |
| 半失能老人 | Semi-disabled Elderly | 部分生活活动需要协助 |
| 失智老人 | Dementia Elderly | 患有认知障碍（如阿尔茨海默病）的老人 |
| 空巢老人 | Empty-nest Elderly | 子女不在身边的独居老人 |
| 适老化改造 | Age-friendly Renovation | 对居家环境进行改造以适应老人需求 |
| 长期照护 | Long-term Care | 为失能老人提供长期护理服务 |
| 安宁疗护 | Hospice Care | 为终末期老人提供临终关怀 |
| 长护险 | Long-term Care Insurance | 长期护理保险，为失能老人提供经济保障 |

## 设备术语

| 术语 | 说明 |
|------|------|
| 毫米波雷达 | 60GHz 毫米波雷达，非接触式检测跌倒、心率、呼吸、在床、活动量、姿态 |
| 跌倒检测 | 雷达核心功能，0=正常 / 1=跌倒，毫秒级实时告警 |
| 心率监测 | 基于雷达微动检测，正常范围 40-120 bpm |
| 呼吸率 | 基于胸腔起伏检测，正常范围 10-30 次/分 |
| 在床检测 | 实时检测老人是否在床上，0=不在床 / 1=在床 |
| 离床报警 | 老人离开床位超过设定时间触发的告警 |
| 活动量 | 基于雷达数据的运动活跃度分级：静止 / 轻微 / 中等 / 剧烈 |
| 姿态识别 | 雷达识别老人当前体态：躺 / 坐 / 站 / 走路 |
| 马桶抽水传感器 | 装在马桶水箱的传感器，通过水流检测使用频次 |
| 门磁 | 开关门状态传感器，Zigbee 协议 |

## 项目术语

| 术语 | 说明 |
|------|------|
| 安伴 Guardian | 本项目产品名，基于 IoT + AI 的智慧养老监控平台 |
| 家属端 | 微信小程序（安伴 Guardian），供家属查看老人健康数据和告警 |
| 管理端 | Web 管理后台（React + Ant Design），供护理员/管理员使用 |
| 绑定码 | 6 位数字码，家属通过小程序输入绑定老人，24 小时过期 |
| 健康日报 | APScheduler 每日 08:00 自动生成，汇总老人前一天健康数据 |
| 雷达采集器 | radar-collector 模块，负责 MQTT 接收雷达数据 → 写入 FastAPI 后端 |

## 产品术语

| 术语 | 说明 |
|------|------|
| Dashboard 概览 | 管理端首页统计：老人总数、在线设备数、活跃告警数、今日跌倒次数 |
| 告警处理状态 | 0=未处理 / 1=处理中 / 2=已处理，护理员操作流转 |
| 日报 | 每日 08:00（APScheduler）自动生成的老人健康小结 |
| 健康评分 | 综合心率、活动量、睡眠、如厕等数据的综合得分 |
| 个人基线 | 基于老人 30 天历史数据建立的个性化正常范围 |
| 误报率 | 错误告警数 / 总告警数，目标 < 15% |
| 告警响应时长 | 从告警发出到护理员标记"已处理"的时间 |
| 设备在线率 | 在线设备数 / 总设备数，目标 ≥ 98% |
