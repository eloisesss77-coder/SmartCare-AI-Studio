# Dify 知识库配置说明

> 本文件由 AIEngineer 维护。

## 知识库创建步骤

### Step 1：准备文档

将知识内容整理为 Markdown 或 TXT 格式，确保：
- 每段 300-500 字（不超过 1000 字）
- 每段有独立标题
- 不要跨主题合并（跌倒和心率分开）

### Step 2：上传到 Dify

```
Dify 管理后台 → 知识库 → 创建知识库
  │
  ├── 名称：SmartCare 养老知识库
  ├── 文档上传：拖入 .md / .txt 文件
  ├── 分段方式：自动分段与清洗
  └── 索引方式：高质量
```

### Step 3：选择 Embedding 模型

| 模型 | 适用场景 | 推荐 |
|------|----------|------|
| `text-embedding-3-large` | 英文为主 | — |
| `bge-large-zh-v1.5` | 中文为主 | ✅ 推荐 |
| `text-embedding-ada-002` | 通用 | 备用 |

### Step 4：检索配置

| 参数 | 建议值 | 说明 |
|------|--------|------|
| Top-K | 3-5 | 返回最相关的 K 个片段 |
| Score 阈值 | 0.5 | 低于此分数的片段不返回 |
| Rerank | 开启 | 二次排序提高精度 |

## 本项目知识库重点方向

基于安伴 Guardian 的业务场景，知识库内容应重点覆盖以下领域：

### 第一优先级：跌倒预防与慢病管理

| 知识方向 | 重要性 | 说明 |
|---------|:------:|------|
| **跌倒预防** | ⭐⭐⭐ | 本项目核心场景。涵盖跌倒风险评估标准、高风险老人照护指南、跌倒后急救流程、居家防跌倒环境改造等 |
| **慢病管理** | ⭐⭐⭐ | 覆盖高血压、糖尿病、心脏病三大高发慢病的日常管理、饮食建议、用药提醒、预警信号识别 |

### 第二优先级：日常护理与安全

| 知识方向 | 重要性 | 说明 |
|---------|:------:|------|
| **用药安全** | ⭐⭐ | 老人常用药相互作用、服药时间建议、漏服处理、药物不良反应识别 |
| **心理健康** | ⭐⭐ | 独居老人孤独感应对、认知障碍早期识别、家属沟通技巧 |
| **适老化生活** | ⭐⭐ | 居家安全指南、季节健康提醒、饮食营养建议、运动康复指导 |

### 知识库检索场景示例

针对本项目实际使用，知识库应能回答以下典型问题：

```
"老人跌倒后家属应该怎么做？"              → 跌倒后急救流程
"高血压老人日常饮食要注意什么？"          → 高血压日常管理
"毫米波雷达检测到心率持续偏高怎么办？"    → 慢性病管理 + 心脏病预警
"老人夜间频繁离床是什么原因？"            → 适老化生活 + 跌倒预防
"如何给老人绑定家属小程序？"              → 产品文档（本项目特有）
```
