1. 通用说明

通用响应格式

{
  "code": 200,
  "message": "success",
  "data": { ... }
}

分页响应格式

{
  "code": 200,
  "message": "success",
  "data": {
    "list": [ ... ],
    "total": 100,
    "page": 1,
    "pageSize": 10
  }
}

认证方式

  • 公开接口：无需认证头
  • JWT 认证：请求头带 Authorization: Bearer <token>
  • 管理端：需 admin / super_admin 角色
  • 小程序端：请求头带 X-Family-Id: <familyId>

请求参数命名

  • 请求体 JSON key 支持 驼峰命名（如 pageSize、deviceSn、ruleName）
  • 响应体 JSON key 统一使用 驼峰命名
  • 路径参数和 Query 参数均支持驼峰别名（如 ?pageSize=10）

{

}

{
  "deviceSn": "NB202607001",
  "deviceCategory": "smoke_detector",
  "timestamp": "2026-07-21T10:30:00",
  "data": { "smoke_ppm": 520 }

6. 告警管理 Alerts

前缀 /api/v1/alerts

方法路径说明认证
POST/api/v1/alerts外部系统创建告警（机器间通信）公开
GET/api/v1/alerts告警列表（分页+按级别/状态/时间筛选）JWT
GET/api/v1/alerts/{alertId}告警详情JWT
PUT/api/v1/alerts/{alertId}/handle处理告警（标记已处理）JWT
GET/api/v1/alerts/rules告警规则列表（分页）JWT
POST/api/v1/alerts/rules新增告警规则JWT
PUT/api/v1/alerts/rules/{ruleId}更新告警规则JWT
DELETE/api/v1/alerts/rules/{ruleId}删除告警规则（仅管理员）JWT

GET /alerts 参数

参数类型必填说明
pageint否页码
pageSizeint否每页数量
levelstring否级别: info / warning / critical / emergency
statusint否处理状态: 0未处理 1已处理
startstring否开始时间
endstring否结束时间

PUT /alerts/{alertId}/handle 请求体

{
  "handledStatus": 1,
  "handledBy": "护工张三",
  "handleRemark": "已前往查看，老人正常"
}

POST /alerts/rules 请求体

{
  "ruleName": "跌倒告警",
  "ruleType": "fall",
  "elderId": null,
  "thresholdValue": "{\"fall_status\":1}",
  "severity": "emergency",
  "enabled": 1,
  "notifyChannels": "wechat,sms"
}
ruleType 可选值说明severity 建议
fall跌倒检测emergency
heart_rate心率异常（<40 或 >120）critical
breath_rate呼吸异常（<10 或 >30）warning
out_of_bed离床超时（>30分钟）warning
smoke烟雾浓度过高critical
gas_leak燃气泄漏emergency
door_open门磁长时间未关warning
sosSOS求救emergency

10. 健康检查

方法路径说明认证
GET/api/health服务健康检查公开

响应：

{ "status": "ok", "service": "安伴 Guardian API", "version": "1.0.0" }

附：常见错误码

HTTP状态码含义常见原因
200成功
400请求参数错误原密码错误/用户名已存在等
401未认证Token 过期或无效、用户名密码错误
403无权限非管理员访问管理接口
404资源不存在ID 对应的记录不存在
422参数校验失败必填字段缺失、参数类型错误、参数命名不匹配
